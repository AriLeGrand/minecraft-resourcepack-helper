# Mockups (reference only)

Static design mockups of the Pack Creator app, exported from the design canvas.
They use a design-tool runtime (`support.js`, `<x-dc>`, `{{holes}}`), so they do
not open as normal web pages: read them for layout, colours, spacing, labels and
behaviour notes. Textures inside are generated placeholders, not game assets.

| File | Screen |
|---|---|
| `Welcome.dc.html` | 1 · Start / new pack |
| `Browser.dc.html` | 2 · Texture browser (list + compare) |
| `AppEditor.dc.html` | 3 · Pixel editor |
| `Animation.dc.html` | 4 · Animation |
| `Export.dc.html` | 5 · Pack settings and export |
| `GuiEditor.dc.html` | 6 · Interface (GUI) editor |
| `Particles.dc.html` | 7 · Particle viewer |

Design document: `../superpowers/specs/2026-11-19-pack-creator-design.md`.
